# Ideal job description

Write the job you actually want, as if it were a real posting. This text is embedded and becomes the
centre of the search — the fetcher pulls the neighbourhood around it, so the wording matters more
than any filter you set later.

Two things to keep in mind:

- **Write a posting, not a résumé.** The corpus is job descriptions, so it matches best against
  something shaped like one. Responsibilities and requirements, not your history.
- **Be specific about tools.** Named technologies are what pull the neighbourhood into focus; vague
  seniority language does not.

Delete everything above this line, and everything below, and write your own.

---

## Senior QA Automation Engineer

We are looking for an experienced quality engineer to own test automation across our web and API
platforms. You will design and maintain the automation framework, lead the shift toward earlier
testing in the delivery cycle, and mentor engineers on testable design.

### Responsibilities

- Build and maintain UI and API automation suites, and keep them fast and non-flaky
- Own the regression strategy: what is automated, what stays manual, and why
- Integrate the suites into CI so every pull request is gated on them
- Work with product and development from refinement onward, not after code is written
- Investigate production defects and close the gaps in coverage that let them through

### Requirements

- 8+ years in software quality engineering, including a technical leadership role
- Strong programming ability in Java, Python, JavaScript/TypeScript or C#
- Deep experience with Selenium, Playwright, Cypress or Puppeteer
- API testing with REST Assured, Postman or equivalent
- BDD with Cucumber/Gherkin; TestNG or JUnit; Maven or Gradle
- CI/CD with Jenkins, Azure DevOps or GitHub Actions
- SQL, and comfort validating data pipelines end to end
- Clear written communication with engineers and non-engineers alike

### Nice to have

- Performance testing with JMeter or k6
- Cloud platforms (AWS, Azure, GCP) and containerised test environments
- Reporting and analytics tooling — Tableau, Power BI, Snowflake
- Accessibility and security testing exposure
